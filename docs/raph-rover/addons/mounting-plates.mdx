Expand Raph Rover’s capabilities with additional mounting plates. Designed to
elevate payloads above the onboard LIDAR sensor, these "sandwich" plates provide
a larger, unobstructed area for integrating custom hardware.

## Installation

The mounting plates are installed using the included M5x40 standoffs. The hole
patterns on the additional plates match the main plate perfectly.

- Remove the existing screws from the main mounting plate.
- Screw in the included M5x25 standoffs in their place.
- Place the new mounting plate onto the standoffs and secure it using the
  original screws.
