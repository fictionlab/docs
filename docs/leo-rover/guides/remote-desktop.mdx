# How to Connect via Remote Desktop (RDP)

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

If you are using the `full` version of LeoOS, you should have a desktop
environment installed, as well as an VNC (Virtual Network Computing) server.
This allows you to remotely control a desktop session on your Rover from your
computer.

Firstly, you will have to connect to the Rover's network:

<LinkButton docId="guides/connect-to-rover-ap" />

Now, to connect to the robot's desktop you have to install and open
[TigerVNC viewer](https://tigervnc.org/)

Type `10.0.0.1` in the **VNC server** field and click **Connect**.
